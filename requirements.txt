# Secure Prompt Assistant for Secure Coding -- application dependencies
#
# Versions are pinned deliberately. The evaluation records scanner versions and
# ruleset hashes with every result, and an unpinned dependency would silently
# break reproducibility between runs.
#
# The SCANNERS are NOT installed here. Each one lives in its own isolated
# virtualenv under .tools/ (python scripts/install_scanners.py) because:
#   * they are external tools invoked as subprocesses, not imported libraries;
#   * Semgrep's dependency pins conflict with FastAPI's (verified: pip backtracks
#     to an old Semgrep sdist that refuses to build on Windows);
#   * isolation keeps a compromised or buggy scanner dependency out of the
#     application's own environment.

# ---- web API ---------------------------------------------------------------
fastapi==0.142.4
uvicorn==0.54.0
python-multipart==0.0.32        # multipart parsing for ZIP uploads and the web interface's forms

# ---- web interface (Phase 7b): server-rendered pages, signed session cookie ----
Jinja2==3.1.6                   # templates, autoescaping forced on (dashboard/web/render.py)
itsdangerous==2.2.0             # signs the session cookie (Starlette SessionMiddleware)

# ---- configuration -----------------------------------------------------------
pydantic==2.13.5
pydantic-settings==2.15.0

# ---- persistence -----------------------------------------------------------
SQLAlchemy==2.1.4

# ---- data files (mapping tables, ground truth) -- always yaml.safe_load ------
PyYAML==6.0.3

# ---- AI layer: local model server (Ollama) over HTTP ----------------------
httpx==0.28.1                   # also used by FastAPI's TestClient

# ---- prompt security linter: our own library, in this repository -------------
# The linter, the untrusted-code delimiting, the injection heuristic and the
# secret patterns live in libs/secure-prompt-lint (no third-party dependencies),
# which is also published on its own. Installed in editable mode, so there is
# one copy of that code. Run pip from the repository root.
-e ./libs/secure-prompt-lint

# ---- shared-server connector: our own client, in this repository -------------
# `spa`, the command a developer runs in their project folder to use a shared
# server (docs/deployment.md). Standard library only. Installed here so the
# end-to-end tests can drive it; developers install just this package.
-e ./libs/spa-connect

# ---- tests -------------------------------------------------------------------
pytest==9.1.1

# ---- review deck generator (scripts/build_review*_deck.py) -------------------
python-pptx==1.0.2

# ---- security floors for transitive dependencies (pip-audit, Phase 9) -------
# Neither is reachable from untrusted input here, but a pinned floor keeps the
# audit of the frozen environment clean. Pillow 13 became possible once the
# Streamlit dashboard (which capped pillow<13) was retired for the web interface.
pillow==13.0.0                  # via python-pptx; 12.3.0 had 8 advisories
certifi==2026.10.19             # via httpx; PYSEC-2026-4320 fixed in this release
