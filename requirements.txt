# Secure Prompt Assistant for Secure Coding -- application dependencies
#
# Versions are pinned deliberately. The evaluation records scanner versions and
# ruleset hashes with every result, and an unpinned dependency would silently
# break reproducibility between runs.
#
# The SCANNERS are NOT installed here. Each one lives in its own isolated
# virtualenv under .tools/ (python scripts/install_scanners.py) because:
#   * they are external tools invoked as subprocesses, not imported libraries;
#   * Semgrep's dependency pins conflict with FastAPI's (verified: pip backtracks
#     to an old Semgrep sdist that refuses to build on Windows);
#   * isolation keeps a compromised or buggy scanner dependency out of the
#     application's own environment.
